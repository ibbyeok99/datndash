# 대시보드 직접 연결 CSV (예정)

이 폴더는 대시보드가 최종적으로 직접 읽는 4종 CSV가 도착할 위치입니다. 아직 파일이 없어도 대시보드는 정상 동작하며, 각 화면은 "데이터 없음" 빈 상태로 표시됩니다. 파일을 이 폴더에 넣고 `python dashboard/build_data.py`를 다시 실행하면 자동으로 반영됩니다.

## 1. `dashboard_품목별_위험현황.csv` (행 단위: 품목분류 1개)

품목분류, 유효공고건수, 계약성립건수, 분석가능건수, 중앙_계약성립소요일수, 평균_계약성립소요일수, p90_계약성립소요일수, 유찰률, 단독입찰률, 재공고율, 계약금액합계, 상위1개사_계약금액점유율, 상위3개사_계약금액점유율, HHI, 리드타임점수, 유찰점수, 단독입찰점수, HHI점수, 종합위험점수, 위험등급, 표본부족여부

메인 위험순위, 지표 카드, 품목 비교 및 위험점수 구성요소 차트에 사용.

## 2. `dashboard_품목별_월별추이.csv` (행 단위: 기준연월 × 품목분류)

기준연도, 기준월, 기준연월, 품목분류, 공고건수, 계약성립건수, 분석가능건수, 중앙_계약성립소요일수, p90_계약성립소요일수, 유찰률, 단독입찰률, 재공고율, 계약금액합계

기간 필터와 월별 리드타임·유찰률·단독입찰률 추이 차트에 사용.

## 3. `dashboard_조달건별_상세내역.csv` (행 단위: procurement_case_id 1개)

procurement_case_id, 공고번호, 공고차수, 공고명, 계약번호, 계약명, 최초공고일, 계약체결일, 계약성립소요일수, 최종품목분류, 분류단계, 분류근거키워드, 분류후보수, 분류검토필요, 최종결과상태, 유찰여부, 단독입찰여부, 재공고여부, 재공고횟수, 참가업체수, 계약방법, 계약업체, 계약금액, 공고계약연결여부, 종합위험점수, 위험등급

품목을 선택했을 때 개별 공고·계약을 조회하는 상세 화면에 사용.

## 4. `dashboard_품목별_업체집중도.csv` (행 단위: 품목분류 × 업체) — 선택(미진행 가능)

품목분류, 업체식별값, 업체명, 계약건수, 배분계약금액, 계약금액점유율, 품목내업체순위, 품목별_HHI, 상위1개사여부, 상위3개사여부, 업체주소, 시도, 시군구, 위도, 경도

## 인코딩

`utf-8-sig` (BOM 포함) 권장 — 기존 EDA CSV와 동일한 관례.
